angular.json
    -This file has the settings for the Angular project. It tells Angular how to build and run the project.
tsconfig.json
    -This is the main TypeScript configuration file. It contains common compiler settings.
tsconfig.app.json
    -This file is used only for the Angular application. It extends the settings from tsconfig.json.
package.json
    -This file contains the project information, dependencies, and npm scripts used to run and build the project.
src/main.ts
    -This is the entry point of the Angular application. It starts the application.
src/app/app.config.ts
    -This file contains the application's configuration such as routing and providers. (In older Angular versions, this file is app.module.ts.)
src/app/app.component.ts
    -This is the main component of the application. It controls the first page displayed.
src/index.html
    -This is the main HTML file loaded by the browser. Angular displays the application inside the <app-root> tag.
